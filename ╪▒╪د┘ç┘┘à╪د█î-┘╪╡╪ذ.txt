مراحل (با GitHub Desktop):

۱) در GitHub Desktop منوی File → New repository
   - Name: gerehgosha
   - Publish repository را بزنید

۲) روی مخزن راست‌کلیک → Show in Explorer
   (پوشه‌ی خالی مخزن روی کامپیوتر باز می‌شود)

۳) همه‌ی محتویات همین پوشه را داخل پوشه‌ی مخزن کپی کنید

۴) در GitHub Desktop همه‌ی فایل‌ها در ستون چپ ظاهر می‌شوند:
   - پایین، یک پیام بنویسید: «انتشار نسخه ۱.۰.۰»
   - دکمه‌ی Commit to main
   - دکمه‌ی Push origin

۵) در مرورگر، تب Actions مخزن را باز کنید:
   دو بیلد همزمان شروع می‌شوند (حدود ۱۰ دقیقه)
   خروجی‌ها در بخش Artifacts:
   - GerehGosha-1.0.0-Android  → فایل APK
   - GerehGosha-1.0.0-Windows → زیپ قابل‌حمل ویندوز
