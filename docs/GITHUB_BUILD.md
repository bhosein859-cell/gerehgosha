# ☁️ ساخت فایل نصبی با گیت‌هاب — روش ساده با زیپ

> کل پروژه داخل **یک فایل زیپ** است؛ فقط ۲ فایل آپلود می‌کنید و تمام!
> سازنده: حسین بختیاری

## قدم ۱ — حساب و مخزن (یک‌بار)
1. در `github.com` ثبت‌نام کنید
2. دکمه **+** → **New repository** → نام `gereh-gosha` → **Create repository**

## قدم ۲ — آپلود زیپ (فقط یک فایل!)
در صفحه مخزن روی **uploading an existing file** کلیک کنید و فایل
**`gerehgosha-source.zip`** را داخل کادر بکشید → **Commit changes**

## قدم ۳ — ساخت فایل موتور گیت‌هاب
1. **Add file → Create new file**
2. در کادر اسم دقیقاً بنویسید:
   `.github/workflows/build.yml`
3. متن کوتاه داخل پروژه (فایل `.github/workflows/build.yml`) را کپی و آنجا پیست کنید
4. **Commit changes**

## قدم ۴ — اجرا و دانلود
- با هر آپلود، ساخت **خودکار** شروع می‌شود؛ یا از تب **Actions** دکمه‌ی **Run workflow** را بزنید
- حدود ۱۰ دقیقه بعد، در صفحه‌ی اجرا → بخش **Artifacts**:
  - `GerehGosha-1.0.0-Android` ← فایل **apk**
  - `GerehGosha-1.0.0-Windows` ← **زیپ قابل‌حمل** + بسته **msix**

## نصب
- **اندروید:** فایل apk را به گوشی ببرید و نصب کنید
- **ویندوز:** زیپ را باز کنید و `gereh_gosha.exe` را اجرا کنید (بدون نصب)

## نکات
- فایل‌های Artifacts تا ۶۰ روز می‌مانند؛ بعدش دوباره Run بزنید
- اگر ساخت قرمز ❌ شد، روی آن کلیک کنید و متن خطا را برای سازنده بفرستید
